Política de Privacidade — QualiAr UFAM

Última atualização: 25 de outubro de 2026

O aplicativo QualiAr UFAM tem como finalidade apresentar informações sobre a qualidade do ar, contribuindo para o acesso público a dados ambientais.

1. Coleta de informações

Na versão atual, o QualiAr UFAM não solicita ao usuário informações pessoais, não exige cadastro e não possui formulários para envio de dados pessoais.

2. Uso das informações

O aplicativo apresenta informações ambientais obtidas por meio de fontes de dados e serviços externos. Essas informações são utilizadas para exibição ao usuário e para a finalidade informativa do aplicativo.

3. Serviços externos

Os serviços externos utilizados para hospedar o aplicativo ou disponibilizar dados ambientais podem processar dados técnicos de conexão, conforme suas próprias práticas e políticas de privacidade. Consulte as políticas dos respectivos provedores para obter mais informações.

4. Compartilhamento e armazenamento de dados pessoais

Na versão atual, o QualiAr UFAM não possui funcionalidade própria para solicitar informações pessoais ao usuário nem mantém uma base própria de informações pessoais dos usuários.

5. Alterações nesta política

Esta política poderá ser atualizada caso novas funcionalidades sejam incorporadas ao aplicativo, incluindo notificações ou outros recursos que envolvam o tratamento de informações. A versão atualizada será publicada nesta página.

6. Contato

Para dúvidas sobre esta política ou sobre o aplicativo, entre em contato com a equipe responsável pelo projeto por meio dos canais institucionais da Universidade Federal do Amazonas (UFAM).
